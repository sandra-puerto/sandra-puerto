# 💫 Sobre mí:
Desarrolladora backend especializada en PHP/Laravel, con una trayectoria previa operando, soportando y dirigiendo infraestructura real — lo que me permite escribir código con conciencia de costo, riesgo y continuidad operativa, no solo de limpieza técnica.

Diseño y modernizo backend en PHP 8, destacando la construcción de un microframework propio bajo estándares Clean Code y PSR, enfocado en estandarizar el ciclo de vida de peticiones HTTP sin romper compatibilidad con sistemas legacy. Complemento ese trabajo con la fase de implementación y despliegue: infraestructura on-premise con Proxmox, Linux, arquitectura Zero Trust (Cloudflare Tunnel, Tailscale) y almacenamiento colaborativo con Nextcloud.

Sumo a esto conocimiento sólido en gestión de activos de TI (ITAM): ciclo de vida, licenciamiento, planeación presupuestal y evaluación de inversión tecnológica (CAPEX/OPEX), priorizando el costo total de propiedad (TCO) sobre el costo inicial — lo que me permite desplegar plataformas robustas incluso en entornos con recursos o presupuesto limitado, sin sacrificar calidad de servicio.

- 💻 **Desarrollo:** PHP 8 / Laravel, microframework propio bajo Clean Code y PSR.
- 🏗️ **Infraestructura:** Virtualización on-premise, redes Zero Trust, alta disponibilidad y continuidad de negocio.
- 🔐 **Seguridad e identidad:** IAM, Active Directory y administración de políticas de seguridad.
- 📊 **Gobierno de TI:** ITAM, análisis CAPEX/OPEX y gestión del ciclo de vida de proveedores y adquisiciones.
- 🤖 **Ingeniería asistida por IA:** uso estratégico de agentes de IA multi-modelo para acelerar entregas fuera de mi stack principal.
